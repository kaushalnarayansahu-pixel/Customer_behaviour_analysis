# Customer_behaviour_analysis
🛍️ Customer Behavior Analysis
A full-stack data analytics project analyzing customer shopping behavior using Python, MySQL, and Power BI.

📌 Project Overview
This project explores a customer shopping dataset to uncover actionable business insights — from revenue drivers and discount effectiveness to customer segmentation and subscription patterns.
The analysis is structured across three layers:

Data Cleaning & Preparation → Python (Jupyter Notebook)
Business Insights via Queries → MySQL
Visual Dashboard → Power BI

🧹 Data Cleaning (Python — Jupyter Notebook)
Dataset: customer_shopping_behavior.csv
Key steps performed:

Loaded and explored the raw dataset (shape, describe, info)
Category remapping — corrected misclassified items into proper categories: Clothing, Accessories, Electronics, Footwear, Outerwear
Null value treatment:

Size → filled based on category logic (e.g., "Free Size" for Accessories, "not available" for Electronics, mode for Clothing)
Review Rating → filled with per-item mean rating
Previous Purchases → filled with 0
Purchase Amount (USD) → filled with per-item mean


Duplicate removal — identified and dropped duplicates by Customer ID
Column renaming — standardized to snake_case lowercase; renamed purchase_amount_(usd) → purchase_amount
Exported cleaned data as cleaned_data.csv for SQL import
